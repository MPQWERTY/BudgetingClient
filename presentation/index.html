Architettura Agentica

5 agenti specializzati, orchestrati.

FILE ─► ORCHESTRATOR │ ├─► PARSER (estrae transazioni) │ │ │ ▼ ├─► ANALYZER (categorizza + narra) │ │ │ ┌───┴───┐ │ ▼ ▼ ├─►SIM ADVISOR (paralleli) │ │ ▼ ▼ STATE ─► UI DASHBOARD

Ogni agente ha input/output JSON tipizzato, fallback deterministico, retry + timeout.

Le istruzioni in agents/*.md sono lette dal frontend come system prompt: la spec vale quello che esegue.

Perché funziona

  • Educazione + comprensione, mai consigli di investimento.
  • Robustezza built-in: ogni LLM ha un fallback deterministico.
  • Trasparenza: le istruzioni degli agenti sono anche il codice che gira.
